# Word list attribution

`eff_large_wordlist.txt` is the **EFF Large Wordlist for Passphrases** by the
Electronic Frontier Foundation, published at
<https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt> (announced in
<https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases>).
It is licensed under the Creative Commons Attribution 3.0 United States
license (CC BY 3.0 US), <https://creativecommons.org/licenses/by/3.0/us/>.

The file is committed unmodified (7,776 lines, `<dice digits><TAB><word>`,
LF line endings). SHA-256 at time of fetch (2026-09-30):
`addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e`.
The generator checks this hash at load time so a silently edited list cannot
change the dataset.

`dev-vocab.json` is original work written for this project (same license as
the repository).
